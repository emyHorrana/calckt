# Android Calculator

This project is a simple calculator application developed in Kotlin for Android devices as part of the Mobile Programming course at the Federal Institute of Southern Minas Gerais (IFSULDEMINAS), Três Corações Campus.

The application implements the four basic arithmetic operations through an intuitive interface, providing hands-on experience with Android development, Kotlin programming, event handling, and user interface design.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal numbers
- Delete last input
- Clear expression
- Calculate result

## Technologies

- Kotlin
- Android Studio
- Android SDK
- XML
